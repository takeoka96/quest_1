# 要件定義書

## 1. プロジェクト概要
- プロジェクト名：女性が活躍する企業・社会への変革提言
- 提言先：日揮ホールディングス株式会社 経営層
- 作成者：岡田孟史
- 作成日：2026-04-13

## 2. 背景
- 2023年の法改正により、女性活躍推進法に基づく多様性指標の有価証券報告書開示が義務化
- 建設・プラント業界は女性活躍が特に遅れている業界の一つ
- 日揮パラレルテクノロジーズ（JPT）は多様性のモデルケースとして日揮HDの特例子会社

## 3. 解決すべき問題
- 建設・プラント業界における女性活躍の現状を定量的に把握できていない
- 業界・企業ごとの課題が明確化されていない
- 具体的な改善施策が提言されていない

## 4. 提言の方向性
- JPTの多様性推進モデルをHDおよび建設業界全体へ横展開する
- データに基づいた具体的な改善施策を提言する

## 5. 成功条件
- EDINETデータによる業界横断分析が完成していること
- 建設業界・日揮HDの課題が定量的に示されていること
- 具体的な提言がプレゼン資料にまとまっていること
- プログラムコードが動作し、GitLabに提出されていること

## 6. 制約条件
- 締め切り：2026年5月15日
- リポジトリサイズ：150MB以内
- 提出先：GitLab quest_1リポジトリ（mainブランチ）
- データの出典を明記すること

## 7. 使用データ
- メイン：EDINETの有価証券報告書データ
- サブ：男女共同参画白書、Global Gender Gap Report、その他公開情報

## 8. 成果物
- プログラムコード（src/、notebooks/）
- プレゼンテーション資料（docs/）
- 分析結果・可視化（notebooks/）
