# 要件定義

## 1. プロジェクト概要
- プロジェクト名：女性が活躍する企業・社会への変革を提言
- 提言先：日揮ホールディングス株式会社 経営企画ユニット
- 作成者：岡田孟史
- 作成日：2026-04-13

## 2. 背景
- 2023年の法改正により、女性活躍推進法に基づく多様性指標の有価証券報告書開示が義務化
- 建設・プラント業界は女性活躍が遅れている業界の一つとされている

## 3. 解決すべき問題
- 建設・プラント業界における女性活躍の現状を定量的に把握できていない
- 業界・企業ごとの課題が明確化されていない
- 具体的な改善施策が提言されていない

## 4. 提言の方向性（仮説）
- 日揮HDおよび建設業界全体への女性活躍推進策を提言する
- データに基づいた具体的な改善施策を提言する
- 海外EPC企業との比較を通じて日揮HDの課題を明確化する

## 5. 成功条件
- EDINETデータによる業界横断分析が完成していること
- 建設業界・日揮HDの課題が定量的に示されていること
- 具体的な提言がプレゼン資料にまとまっていること
- プログラムコードが動作すること

## 6. 制約条件
- データの出典を明記すること
- APIキーはgitignore対象

## 7. 使用予定データ
- メイン：EDINETの有価証券報告書データ
- サブ：Global Gender Gap Report、その他公開情報・官公庁統計

## 8. 成果物
- プログラムコード（src/、notebooks/）
- プレゼンテーション（docs/プレゼンテーション.pdf）
- 提言書（docs/提言書.md）
- 仕様書（docs/仕様書.md）
- 要件定義書（docs/要件定義.md）
