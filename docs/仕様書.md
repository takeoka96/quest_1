# 仕様書

## 1. システム概要
- EDINETから有価証券報告書データを取得し、業界・企業ごとの女性活躍指標を分析する
- 分析結果をもとに日揮ホールディングスへの提言を行う

## 2. 入力データ
| データ | 取得元 | 内容 |
|---|---|---|
| 有価証券報告書 | EDINET API | 女性管理職比率・男性育児休業取得率・男女間賃金格差・売上高・純利益 |
| 業界分類 | EDINETコードリスト | 業種コード |
| 国際比較データ | JILPT「データブック国際労働比較2025」 | 各国女性管理職比率 |
| 日揮HD詳細データ | 日揮HD公式サイト・JGC Report 2025 | 女性管理職推移・目標達成状況 |
| 認定実績 | 厚労省えるぼし認定企業一覧 | グループ会社の認定状況 |
| ESG参考データ | 内閣府「機関投資家が評価する企業の女性活躍推進と情報開示」 | 機関投資家の評価動向 |

## 3. 出力データ
| 出力 | 形式 | 内容 |
|---|---|---|
| 分析結果 | CSV | 業界・企業ごとの女性活躍指標一覧 |
| 可視化 | PNG | グラフ・チャート（fig01〜fig08） |
| 提言資料 | PDF | 日揮HDへの提言プレゼン |

## 4. 分析内容
### 4.1 業界横断分析
- 全業界の女性管理職比率・男性育児休業取得率・男女間賃金格差を比較
- 建設業界の位置づけを明確化

### 4.2 企業個別分析
- 日揮HDの各指標を業界平均と比較
- EDINETデータと公式サイトデータの定義の違いを整合

### 4.3 相関分析
- 女性活躍指標と企業業績の相関分析
- 相関ヒートマップ・散布図で可視化

### 4.4 クラスタリング分析
- K-meansで建設業142社を3グループに分類
- 女性管理職比率・男性育児休業取得率の2軸で分析
- 日揮HDの業界内ポジションを特定

### 4.5 機械学習モデル分析
- ランダムフォレスト（ベースライン）
- LightGBM（GridSearchCVでハイパーパラメータ最適化）
- 評価指標：R²・MAE

### 4.6 説明可能AI分析
- SHAP分析：特徴量重要度の算出
- LIME分析：個別予測の説明
- 両分析の結果を照合し信頼性を確認

### 4.7 国際比較
- JILPT「データブック国際労働比較2025」を用いた国際水準との比較
