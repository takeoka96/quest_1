# 仕様書

## 1. システム概要
- EDINETから有価証券報告書データを取得し、業界・企業ごとの女性活躍指標を分析する
- 分析結果をもとに日揮ホールディングスへの提言を行う

## 2. 入力データ
| データ | 取得元 | 内容 |
|---|---|---|
| 有価証券報告書 | EDINET API | 女性管理職比率・男性育児休業取得率・男女間賃金格差 |
| 業界分類 | EDINET | 業種コード |
| 補助データ | 男女共同参画白書等 | 社会全体の女性活体指標 |

## 3. 出力データ
| 出力 | 形式 | 内容 |
|---|---|---|
| 分析結果 | CSV | 業界・企業ごとの女性活躍指標一覧 |
| 可視化 | PNG/HTML | グラフ・チャート |
| 提言資料 | PDF/PPT | 日揮HDへの提言プレゼン |

## 4. 分析内容
### 4.1 業界横断分析
- 全業界の女性管理職比率・男性育児休業取得率・男女間賃金格差を比較
- 建設・プラント業界の位置づけを明確化

### 4.2 企業個別分析
- 日揮HDの各指標を業界平均・上位企業と比較
- 経年変化の分析

### 4.3 仮説検証
- 女性活躍指標と企業業績の相関分析
- 改善施策の効果予測
