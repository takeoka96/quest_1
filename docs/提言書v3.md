# 提言書v3：女性が活躍する企業・社会への変革

## 提言先
日揮ホールディングス株式会社 経営層

## 提言日
2026年4月

## 作成者
岡田孟史

---

## 1. 背景・目的

2023年の法改正により、女性活躍推進法に基づく以下の3指標の有価証券報告書での開示が義務化された。

- 女性管理職比率
- 男性育児休業取得率
- 男女間賃金格差

本提言は、EDINETの有価証券報告書データを分析し、建設業界および日揮HDの現状を定量的に把握した上で、女性活躍推進に向けた具体的な変革を提言するものである。

---

## 2. 日揮HDの取り組み評価

### 2.1 制度面での充実
日揮グループはプラント建設業界において、以下のファミリーケア制度を整備し、女性が働きやすい環境づくりを推進している。

- 子の看護休暇・育児休職・育児短縮勤務・子育て支援勤務
- 介護休暇・介護休職・在宅勤務
- Welcome Back制度（配偶者の転勤による退職者を再雇用）

### 2.2 認定実績
日揮グループでは子会社レベルで女性活躍・子育て支援の認定実績がある。

- 日揮株式会社：くるみん認定（2007・2012・2017年）
- 日本エヌ・ユー・エス株式会社：えるぼし三つ星・くるみん認定取得

### 2.3 目標達成状況
JGC Report 2025によると、エンジニアリング関連4社（日揮ホールディングス株式会社・日揮グローバル株式会社・日揮株式会社・日揮コーポレートソリューションズ株式会社）において、「2025年までに女性管理職者数を2020年比で2倍（60名）にする」という目標を掲げていたが、2025年7月時点で63名（比率4.5%）に達し、**前倒しで達成**している。

### 2.4 課題：制度・認定・目標達成と実態のギャップ
しかし以下の事実が存在する。

- EDINETデータ（2024年3月期）における日揮ホールディングス単体の女性管理職比率は**3.3%**
- エンジニアリング関連4社合算でも**4.5%**（2025年7月時点）
- 国際水準（スウェーデン43.7%）の約**1/10以下**
- 政府目標（2030年までに30%）まで**大きな開き**がある

制度・認定・目標達成という**形式面では先進的**であるにもかかわらず、**絶対値としては依然として極めて低水準**にある。

## 3. なぜ数字に結びついていないのか

プラント建設業界には以下の構造的障壁が存在する。

1. **母集団の問題**：理工系技術者が社員の多くを占め、女性の母集団が少ない
2. **業務環境の問題**：海外・イスラム圏プロジェクトが多く、女性が参画しにくい環境
3. **現場環境の問題**：厳しい自然環境下での建設工事遂行
4. **目標水準の問題**：達成した目標（4.5%）自体が国際水準と比較して低すぎる

これらは個社の努力だけでは解決困難な業界特有の構造的課題である。

---

## 4. 現状分析サマリー

### 4.1 業界横断分析
- 建設業の女性管理職比率は全30業界中**ワースト2位（3.0%）**

### 4.2 国際比較
- 日本全産業平均（14.6%）でも欧米諸国の3分の1以下
- 建設業（3.0%）は国際水準（スウェーデン43.7%）の約14分の1
- 政府目標（2030年までに30%）には大きな開きがある

### 4.3 SHAP分析からの示唆
- 企業規模（売上高）が女性管理職比率に最も影響
- 日揮HDは売上高約4,800億円の大企業→リソースを活用した変革が可能

---

## 5. 提言

### 提言1：目標水準の抜本的引き上げ（短期：〜2027年）
- 現行目標（4.5%）を大幅に上回る新目標の設定
- 女性管理職比率：**2030年までに15%**（政府目標30%への中間マイルストーン）
- 根拠：現行目標達成済み・国際水準との大きな乖離

### 提言2：母集団形成（中期：〜2030年）
- 理工系女性の採用強化（新卒・中途）
- 大学・高専との連携による女性エンジニア育成
- 根拠：母集団が少ないことが根本的な課題

### 提言3：海外プロジェクトへの女性参画（中期：〜2030年）
- 海外プロジェクトへの女性参画推進
- イスラム圏等の文化的配慮を含めた海外勤務支援制度の整備
- 根拠：業務環境の構造的障壁の解消

### 提言4：グループ内先進事例の全社横展開（中期：〜2030年）
- 日本エヌ・ユー・エス株式会社のえるぼし三つ星取得ノウハウをグループ全体に展開
- グループ横断での女性活躍推進体制の構築
- 根拠：グループ内に先進事例が存在するにもかかわらず全社展開できていない

### 提言5：業界標準の設定（長期：〜2035年）
- 建設業界団体への積極的働きかけ
- 日揮グループの取り組みを業界標準として展開
- 根拠：建設業ワースト2位という構造的課題は個社努力では解決困難

```
日揮HDの変革
　↓
建設業界全体の標準が変わる
　↓
日本のジェンダーギャップ改善に貢献

```

制度・認定・目標達成という形式面で先行している日揮HDが、
データに基づいた目標水準の引き上げと構造的障壁の解消をリードすることで、
建設業界全体のロールモデルとなり、日本社会全体の女性活躍推進に貢献できる。
